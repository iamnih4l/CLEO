# Super Intelligence (SI) & AI Tool Disclosure (`SI_DISCLOSURE.md`)
## 2026 NASA Space Apps Challenge Compliance Statement

In full compliance with the [2026 NASA Space Apps Challenge](https://www.earthdata.nasa.gov/data/tools/firms) rules regarding transparency and Super Intelligence (SI) / generative AI usage, this document discloses how AI assistance was used during the architecture, engineering, testing, and documentation of **CLEO**.

### 2. Scientific Integrity & Anti-Fabrication Guarantees
1. **Zero Fabricated Satellite Detections**: All 70 reference hotspots in CLEO's default **Verified NASA Reference Archive** mode are verbatim records retrieved from the [NASA FIRMS API Python Academy Tutorial](https://firms.modaps.eosdis.nasa.gov/content/academy/data_api/firms_api_use.html) and [UN OCHA HDX NASA FIRMS Active Fire Feeds](https://data.humdata.org/en/dataset/nasa-firms-active-fire-south-asia-viirs/resource/b8a89bec-56e5-4a69-9622-b01133374654).
2. **Strict Segregation of Synthetic Test Fixtures**: CLEO includes an optional algorithmic calibration fixture (`SYNTHETIC_DEMO_FIXTURE`) solely for stress-testing UI grid density and calendar pagination when offline. When enabled, it displays a persistent warning banner, is excluded from authentic NASA scientific statistics, and is watermarked as `SYNTHETIC_DEMO_FIXTURE` in any export.
3. **No Manufactured Cross-Sensor Calibration Coefficients**: In accordance with Earth observation best practices, CLEO does not invent a physical calibration regression between MODIS (`1 km`) and VIIRS (`375 m`). Instead, it uses common spherical equal-area spatial aggregation (`Active Cell-Days` and detections per $1,000\text{ km}^2$) alongside sensor-stratified analytics.
